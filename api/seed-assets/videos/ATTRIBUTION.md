# Seed video assets — attribution

These are real, freely-licensed sample videos used only to populate demo lesson
content so the custom video player has something real to stream. Swap them out
for your own lesson recordings via the admin "Upload video" flow whenever you're ready
— nothing in the app depends on these specific files.

- **big-buck-bunny.mp4** — from the Blender Foundation's "Big Buck Bunny" open
  movie project. Licensed CC BY 3.0. © 2008, Blender Foundation / www.bigbuckbunny.org
- **echo-hereweare.mp4** — sample clip distributed with the MediaElement.js
  project's open-source demo assets (github.com/mediaelement/mediaelement-files).

Both are widely used, standard sample/test videos safe for demo and educational use.
